# Font licenses

The three typefaces used by this site are self-hosted from `public/fonts/`. No font is requested
from a third-party origin at runtime, and nothing blocks first paint on a network font request.

Each family is licensed under the **SIL Open Font License, Version 1.1** (OFL-1.1), which permits
use, modification, and redistribution — including self-hosting and web embedding — provided the
license notice travels with the font files.

| File | Family | Upstream | License |
| --- | --- | --- | --- |
| `instrument-serif.woff2` | Instrument Serif, 400 | [Instrument](https://github.com/Instrument/instrument-serif) | OFL-1.1 |
| `inter.woff2` | Inter, variable weight | [Inter](https://github.com/rsms/inter) | OFL-1.1 |
| `jetbrains-mono.woff2` | JetBrains Mono, variable weight | [JetBrains Mono](https://github.com/JetBrains/JetBrainsMono) | OFL-1.1 |

The files distributed here are latin-subset WOFF2 builds obtained from the
[Fontsource](https://fontsource.org/) CDN, which repackages the upstream projects without changing
their license. They are redistributed unmodified.

Full license text: <https://openfontlicense.org/open-font-license-official-text/>
